# Data Dictionary

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| Row ID | Integer | Unique row number |
| Order ID | Text | Unique identifier for each order |
| Order Date | Date | Date when the customer placed the order |
| Ship Date | Date | Date when the order was shipped |
| Ship Mode | Text | Shipping method used |
| Customer ID | Text | Unique customer identifier |
| Customer Name | Text | Customer full name |
| Segment | Text | Customer segment (Consumer, Corporate, Home Office) |
| Country | Text | Customer country |
| City | Text | Customer city |
| State | Text | Customer state |
| Postal Code | Integer | Postal code |
| Region | Text | Sales region |
| Product ID | Text | Product identifier |
| Category | Text | Product category |
| Sub-Category | Text | Product sub-category |
| Product Name | Text | Product name |
| Sales | Decimal | Sales amount |
| Quantity | Integer | Quantity sold |
| Discount | Decimal | Discount applied |
| Profit | Decimal | Profit earned |
